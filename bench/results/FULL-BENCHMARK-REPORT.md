## Key Findings

### 1. Startup Time
- **Pumpkin** is the fastest at **516ms** (no JVM overhead)
- **Vanilla** is second at **7,600-8,200ms**
- **Paper** and **Folia** are similar at **8,600-8,700ms** (extra plugin overhead)

### 2. Join Latency (10 bots)
- **Paper** is fastest: **2,757ms** (optimized networking)
- **Folia** is close: **2,878ms**
- **Vanilla** is slowest: **3,722ms**

### 3. Join Latency Scaling
- 10 → 100 bots: ~4x slower (expected)
- 100 → 1000 bots: ~6x slower (batched threads add overhead)
- All servers scale similarly — the bottleneck is the bot harness, not the server

### 4. RAM Usage
- All Java servers use **~2.4 GB** (2GB heap + overhead)
- **Pumpkin** uses only **20 MB** (no JVM)
- RAM is consistent across bot counts — server doesn't grow with players

### 5. CPU Usage
- **Paper** uses most CPU (50% peak at 10 bots) — plugin overhead
- **Folia** is efficient (2-6% peak) — threaded regions distribute load
- **Vanilla** is moderate (1.5-28% peak)

### 6. Pumpkin Limitation
- Starts in **516ms** (fastest)
- Uses only **20 MB RAM** (most efficient)
- **Cannot accept bot connections** — "Failed to verify username!" bug
- Needs offline mode fix before it can be benchmarked properly

## Known Issues

1. **TPS Measurement:** Spark HTTP API not responding on Windows. Code is ready but needs spark HTTP enabled.
2. **Pumpkin Offline Mode:** Bots cannot connect due to username verification bug.
3. **Join Latency Overhead:** Azalea bots have higher overhead than mineflayer (not comparable to baseline B0).
4. **1000 Bot Latency:** High p50 (101s) due to batched thread pool (50 bots per batch).

## Methodology

- Each test: 1 run, 10s warmup, join-storm scenario
- Bots: azalea (Rust, Minecraft 26.2 protocol)
- Metrics: startup time, join latency, RAM (RSS), CPU (%)
- Output: JSON + Markdown per test, comparison table via `neutron-bench compare`

## Recommendations

1. **For vanilla-like performance:** Vanilla is fine for <100 players
2. **For optimized performance:** Paper is best for join latency
3. **For massive scale:** Folia is most CPU-efficient at 1000 players
4. **For minimal resources:** Pumpkin is ideal once offline mode is fixed
5. **For Neutron targets:** Need startup <2s, RAM <150MB, CPS >250
