# run-001 — F0: Fundamentos y harness (baseline B0)

## Objetivo
Infraestructura completa de benchmarks: harness multi-servidor, bots multi-conexión, docs del harness, y primer baseline público B0 reproducible.

## Bar (de ROADMAP.md)
Un agente distinto al builder ejecuta `bench/run.ps1` desde cero en Windows y Linux y reproduce el baseline B0 (vanilla 26.2 / Paper / Pumpkin); 10 bots de join simultáneo sin kicks (p95 < 5 s); cps ±30% consistente con baselines publicados.

## Tareas

### T1 — Harness de benchmarks (`bench/run.ps1` + `bench/run.sh`)
- **Qué**: scripts orquestadores que levantan servidor → ejecutan bots → miden métricas → producen JSON + markdown
- **AC**: Soporta vanilla/Paper/Pumpkin/Neutron; warmup 60s; N=5 runs (mediana); produce JSON en `bench/results/` y markdown resumen; mide startup (regex `Done (Xs)!`), join latency (p50/p95/p99), RAM (RSS), cps, TPS; pasa `--version` al bot correctamente
- **Evidencia**: `bench/run.ps1` (31KB), `bench/run.sh` (30KB) — ambos funcionales con parámetros completos
- **DoD**: El critic ejecuta `.\bench\run.ps1 -Server vanilla -N 10 -Runs 1` en Windows y verifica que produce JSON y markdown en `bench/results/`

### T2 — Bots multi-conexión (`bench/bots/join-bench/`)
- **Qué**: Script Node.js que conecta N bots simultáneos y mide p50/p95/p99 de join time
- **AC**: 10 bots simultáneos sin kick (stagger ~2ms); acepta `--host`, `--port`, `--count`, `--version`, `--output`; outputs JSON con per-bot timestamps y percentiles; usa `physicsEnabled: false` para 1.20.2+; timeout de 15s por bot; valores en ms (no segundos)
- **Evidencia**: `bench/bots/join-bench/index.js` (12KB), `package.json` con mineflayer ^4.37.1, `node_modules/` instalado
- **DoD**: El critic ejecuta `node index.js --count 3 --version 26.2` contra servidor local y verifica que produce JSON con `aggregate.join_p50_ms`

### T3 — Documentación del harness (`bench/README.md`)
- **Qué**: Documentación completa del sistema de benchmarks
- **AC**: Cubre quick start, prerequisites, arguments, how it works, output format, server types, bots, interpreting results, baselines, troubleshooting, extending, CI integration
- **Evidencia**: `bench/README.md` (680 líneas, ~25KB) — documentación exhaustiva con ejemplos de uso
- **DoD**: El critic verifica que la documentación cubre todos los puntos de la checklist

### T4 — Baseline B0 (`bench/results/baseline-B0.json`)
- **Qué**: Baseline reproducible ejecutando el harness completo contra Vanilla 26.2, Paper, Pumpkin y Neutron
- **AC**: Resultados publicados con timestamps, hashes, metodología reproducible; formato JSON + markdown
- **Evidencia**: (PENDIENTE — requiere servidores descargados)
- **DoD**: El critic ejecuta `bench/run.sh vanilla -n 10 --runs 5` en Linux y verifica que los números son consistentes con baselines publicados (±30%)
