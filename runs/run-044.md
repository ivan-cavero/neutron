- **Fix**: `aquifer.rs::create()` computes the preliminary level like
  `NoiseChunk.computePreliminarySurfaceLevel` (4×4×4 sampling, chunk rectangle).
  - `get_seed` with int wrap like `Mth.getSeed` (x*3129871).

  `maxPreliminarySurfaceLevel=96, skipSamplingAboveY=130`; neutron now matches 1:1.
- **Numbers (builder)**: air→water 7149→**0** (9/9 chunks) · REGION ALL 424242
  89.07→**96.03%** · 12345 no regression (97.74%) · tests 58/58.
- Independent critic verification: **PASS** (2026-08-15). Re-ran everything from
  scratch: air→water=0 (via `aquifer_diag`, not just the top-30 table hiding 222
  mismatches) · REGION 96.03%/97.74% · tests 58/58 · line-by-line inspection vs
  `Aquifier.java`/`NoiseChunk.java`/`Mth.java` conforms. Note: two hung
