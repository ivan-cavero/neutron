## ✅ T1 — Marker wrapping IMPLEMENTADO

**Completo**: Marker caching system compilando, 380 markers integrados en el router.

### Implementación

1. **`MarkerState`** — estado mutable de caching (en `density.rs`):
   - `last_pos_2d: Option<i64>` — clave para Cache2D/CacheOnce
   - `last_value: f64` — último valor cacheado
   - `interpolation_counter: i64` — counter por bloque para CacheOnce
   - `flat_cache: HashMap<(i32, i32), f64>` — QuartPos XZ → value
   - `cell_cache: HashMap<String, Vec<f64>>` — cell key → values
   - `cell_width: usize, cell_height: usize` — para CacheAllInCell

2. **`DensityEnv::marker_state: Option<&'a mut MarkerState>`** — referencia mutable al estado
   - `DensityEnv::new(...)` → marker_state = None (sin caching, ej: aquifer)
   - `DensityEnv::with_markers(...)` → marker_state = Some(state) (con caching, ej: fill loop)

3. **`compute()` cambia a `&mut DensityEnv`** — permite mutating el state durante evaluación

4. **Marker handler en `compute()`** — patrón immutable-check / mutable-compute / mutable-store:
   - Primero verificar cache con `as_ref()` (borrow inmutable)
   - Si miss, llamar `compute(wrapped, env)` con `&mut env`
   - Luego guardar resultado con `as_mut()` (borrow mutable)
   - NUNCA dos borrows simultáneos → sin RefCell, sin borrow conflicts

5. **`sub()` eliminado** — se reemplaza con inline Y-swap: `env.y = Y; compute(...); env.y = old_y`
   - `Option<&'a mut T>` no implementa Clone en Rust estable
   - Inline swap es más simple y evita el problema

6. **Generator.rs** — per-chunk `MarkerState`, incrementa `interpolation_counter` por bloque:
   - Grid sampling: usa `DensityEnv::new()` (sin markers)
   - Fill loop: usa `DensityEnv::with_markers()` (con markers)
