### Problemas resueltos

1. **Cascading updates infinite loop**: Resuelto con pop_front + HashMap counter (MAX_PER_BLOCK=10)
2. **Torch burnout no detecta**: place_solid no activaba neigh() → torch nunca veía cambio. Fix: add neigh() en place_solid y remove_block.
3. **Doors no se cierran**: rpow no llamada para doors/levers fuera del update_queue. Fix: add per-tick rpow call.
4. **Push no funciona (core bug)**: is_pushable no incluía BlockType::Solid → push_blocked siempre true. Fix: added Solid to pushable list, changed extend_pis logic from "continue if pushable" to "return if not pushable".
5. **Corrupt files from concurrent agents**: Duplicate #[cfg(test)], duplicated code in extend_pis, corrupted test functions. Fix: manual cleanup, rewrite of test_sticky_piston.
6. **Sticky piston pulled_block nunca se setea** (critic Gap 1): extend_pis nunca registraba qué bloque empujar. Fix: tracked `first_pushed` during push loop, set in `pulled_block` meta, cleared after retract.
