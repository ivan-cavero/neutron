## Resultado (15 ago 2026 — diagnóstico de referencia)

**El run pivota**: la investigación de T1 (dark oak) destapó un problema de
metodología mayor que los gaps individuales.

- `level.dat` de 26.2 no guarda seed; el mundo nunca se regeneró tras el 9 ago.
- Mundo fresco seed 12345 (mismo jar) vs viejo: 98.75 % — 1233 diffs de vegetación.

### Hallazgo 2 — Vanilla 26.2 NO es determinista en decoración
Dos corridas idénticas (mismo jar, seed 12345, spawn-prep): **99.05 %, 938
diffs — 100 % vegetación, 0 diffs de terreno**. Causa: decoración paralela +
features cross-chunk (postponement cambia heightmaps/`would_survive` vecinos).

van-vs-van, no 100 %.

### Bar
**DECIDIDO (gate humano, 15 ago 2026): paridad de MECANISMO.** "Quiero que se
comporte como vanilla: si algo no es determinista en vanilla, usar el mismo
mecanismo random que vanilla." Concretamente:

1. Mismos seeds → mismos streams de RNG (`setDecorationSeed`/`setFeatureSeed`
   / positional RNG) bit a bit.
2. Mismos algoritmos por feature (port CFR línea a línea).
3. Fases deterministas (terreno/ores/estructuras/sculk/bedrock) → 100 %
   block match multi-seed contra referencias frescas.
4. Vegetación → mismo stream por chunk (verificable con probes Java); el
   orden serial de decoración de Neutron produce una salida válida dentro del
   espacio de salidas de vanilla.
