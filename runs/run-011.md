## Gaps restantes para 1:1 byte-identical NBT

1. **Features phase** (árboles, ores dispersos, clay, gravel patches, sculk, flowers…)  
   — no es density; es el pipeline `Biome.features` + `PlacedFeature`. Vanilla chunk
   tiene dark_oak_leaves, coal_ore, andesite, diorite, sculk, etc. que salen de ahí.
2. **Bandlands** exactas (clay_bands array + offset noise) — aproximación Y-mod.
3. **Carvers** clásicos (canyon/cave carvers post-noise) si 26.2 aún los usa aparte del density.
4. **Biome 4×4×4** storage completo.
5. **Paridad multi-seed** con golden hashes.

## Realismo

Cerrar **hashes idénticos** requiere la fase de **features** completa (~cientos de
configured/placed features del datapack). El terreno base + surface + ore veins
ya es el “raw terrain” de vanilla antes de vegetación/decoración.
