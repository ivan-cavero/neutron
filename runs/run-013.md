## Por qué aún no es 1:1 byte

| Gap | Impacto | Qué hace falta |
|-----|---------|----------------|
| OreFeature positions | Alto | Algoritmo + RNG bit-idéntico al jar (y orden de gen del servidor) |
| Clay disks / gravel disks | Medio | `DiskFeature` + heightmap OCEAN_FLOOR_WG |
| Árboles dark forest | Alto visual | `dark_forest_vegetation` + tree placers |
| Sculk (deep dark) | Medio | features sculk patch |
| Density residual 1.2% | Alto para hash | Probe bloque-a-bloque density/aquifer vs Java |
| NBT packing | Hash only | palette order, properties, section omit |
