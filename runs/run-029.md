```
nextFloat() < 1.0f / (float) chance
```

Neutron usaba `nextInt(chance) == 0`. Misma probabilidad media, **otro draw**: desincroniza xz/y del feature y puede “pasar” cuando vanilla no.

Probe jar, seed 12345, origen (96,-32), índice 6:

```

1/6=0.16666667
vanilla_place=false
```

## 3. Fix

`CountSpec::Rarity` + ambos `rarity_filter` de `feature_dispatch` → `next_f32() < 1.0 / chance`.
