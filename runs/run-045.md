### T1-R2 — per-cell premise CORRECTED; spillover isolated (16 Aug; budget)

- **Premise correction (source evidence)**: the per-cell 4×4 loop is pre-1.18.
  In 26.2 `applyBiomeDecoration` (ChunkGenerator.java:263-333) iterates
  steps→features (global FeatureSorter index) and per feature does
  `setFeatureSeed(decorationSeed, globalIndex, stepIndex)` (L318) +
  `placeWithBiomeCheck` (L321). Biome gating lives in the placement modifiers
  (`BiomeFilter.java:29-35`, `InSquarePlacement`) — already implemented. So R2
  did NOT apply per-cell (it would have changed the step-9 RNG stream and broken
  REGION ALL). Bar protected.
- **Inflated clay root cause (840 vs 497)**: over-decoration of the **9 chunks**
  in `apply_step_region` (feature_dispatch.rs:32-114) — the 8-neighbor spillover
  floods the center chunk. Probe `clay_overlap`: `lush_caves_clay` isolated =
  411 clay, 3D overlap only 138/411. RNG index rejected by brute-force
  (idx 20..39 → overlap 26-36/55 even).
- **Correct model (run-046)**: center chunk = its own features (≈411) + real
  neighbor spillover with its own per-chunk decorationSeed and biome-filter gate.
  That is the cross-chunk input model (T2).
- New probes (compile, registered): `lush_pale_diag`, `clay_probe`,
  `clay_rng_probe`, `clay_overlap`.
- **Numbers (LEAD-verified)**: 424242 REGION **97.28%** ✓ · 12345 **97.75%** ✓ ·
  tests 59/59 · clean check.
